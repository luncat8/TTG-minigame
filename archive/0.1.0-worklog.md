# 0.1.0 worklog

## Steps

1. Read `draft.txt`, `AGENTS.md`, and the plan. Reviewed the plan for gaps: missing player and board-size ranges, undefined handling of a removed player's marks, resize with gravity, game-over rule, and snapshot semantics for deferred matches.
2. Revised the plan (now `archive/0.1.0-plan.md`) to resolve those gaps. Chosen values: 2–6 players (default 3), board size 5–11 (default 7), controllers default to Human, a removed slot keeps its marks and score, resize settles without scoring, and a rule change refreshes the snapshot without awarding points.
3. Implemented the pure model in `src/model.js`: typed-array board buffers, precomputed window and line tables per size, stable settling in four directions, window and group detection, scoring with a snapshot, simultaneous removal, turn flow, resize, rule changes, and Clean.
4. Implemented the bot in `src/bots.js`: a registry with one strategy, `gravity-heuristic`. It simulates each candidate on scratch boards and scores immediate points, standing-three balance (weight 1.5), and the next player's best reply (denial).
5. Implemented the page: `index.html`, `style.css`, `src/render.js` (canvas board, gravity bar and arrow, pastel symbols), and `src/app.js` (controls, keyboard input, bot scheduling, status text).
6. Added `test/model.test.js` and `test/bots.test.js` (`npm test`) and `experiments/selfplay.js` with its log.

## Validation

- `npm test`: 45 tests pass on Node 22. They cover gravity in all four directions and stable order, horizontal, vertical, and diagonal windows, overlapping windows, 4-connected versus diagonal-only groups, each rule toggle, repeated versus newly formed scoring including deferred matches, resize, player-count changes, Clean, rotation once per turn, full-board termination, and bot legality, non-mutation, and targeted preferences.
- Headless Chromium smoke test on `file://`: no console errors; a human click places and passes the turn; bot turns run with their rotation and placement delays; keyboard rotate and place work; a board-size change during a bot's turn reschedules it without clearing the board; Clean resets the game.
- Self-play, 40 games per threshold, default rules, 7×7, three bots (`experiments/logs/0.1.0-selfplay-threshold.txt`):
  - threshold 4: 88 group-clear turns per game, 213 points per game over 502 turns
  - threshold 5: 60 group-clear turns per game, 363 points per game over 417 turns
  - Threshold 5 scores more per turn, but the bot was tuned with threshold 4, so this is not conclusive. The default stays at 4.
