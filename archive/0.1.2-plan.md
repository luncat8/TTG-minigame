# 0.1.2 — Every-turn gravity rotation rule

## Objective

Add an opt-in rule that advances gravity one step at every turn boundary, so the board reshapes itself between moves without any player action.

## Rule semantics

- New rule key `rotateGravityEachTurn`, default off, rendered as the last checkbox of the rules list with the label `Rotate gravity every turn`.
- After a placement resolves and before the next player acts, gravity advances one step clockwise: down → left → up → right → down.
- The turn boundary rotates the direction only. The board restacks toward the new edge on the next placement, exactly as the existing manual rotation does; no scoring, removal, or snapshot refresh happens at the boundary.
- The turn that fills the board ends the game without rotating.
- Manual rotation stays available once per turn and stacks with the automatic one, so a turn can rotate twice in total. `rotatedThisTurn` still caps the manual part.
- Enabling the rule mid-game takes effect from the next turn end. `Clean` resets gravity to down, so the first turn of a new game always starts at down.

## Model

- `finishTurn` advances gravity through a shared `advanceGravity` helper when the rule is on; `rotateGravity` uses the same helper.
- The rule lives in `RULE_DEFINITIONS` like every other toggle, so defaults, the checkbox list, `setRule`, and `clean` keep working unchanged.

## Bot

- `bestReplyGain` evaluates the next player at the gravity the turn leaves them: the inherited direction under the rule, plus their own one manual rotation. Without the rule the base stays the current gravity.
- `evaluateCandidate` restacks the trial board toward the inherited gravity before measuring standing balance, because the next placement restacks every line. Scoring from the move itself is unchanged, so `gained` and `conceded` keep their meaning.

## UI

- The status line names the automatic rotation while the rule is on. The rotate button stays enabled and keeps naming its next direction, because a manual step still shifts the inherited direction by one more.

## Acceptance criteria

- The rules list gains an unchecked `Rotate gravity every turn` checkbox.
- With the rule on, gravity cycles through all four directions across four turns and the turn passes normally.
- With the rule off, gravity holds between turns, identical to before.
- Manual rotation remains once per turn and adds one step on top of the automatic rotation.
- Enabling the rule mid-game does not rotate the turn in progress.
- A full board ends the game without a final rotation.
- Bot decisions are byte-identical to the previous build whenever the rule is off.
- All Node tests and a headless-browser interaction pass without console errors.
